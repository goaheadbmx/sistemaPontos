# Guia instalação

descompacte o arquivo .zip
acesse via terminal a pasta
crie o ambiente virtual do python
> digite no terminal python.exe -m venv .venv
ative o ambiente virutal
> .\venv\Scripts\activate
instale as dependencias
> pip install -r requirements.txt
execute o app.py
> python.exe app.py
acesse pelo navegador
> http://localhost:5000
